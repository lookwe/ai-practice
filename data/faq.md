# 常见问题解答 (FAQ)

## 账户相关

### Q1: 如何注册账号？
**A:** 访问官网首页，点击右上角"注册"按钮，填写邮箱、密码等基本信息即可完成注册。

### Q2: 忘记密码怎么办？
**A:** 在登录页面点击"忘记密码"，输入注册邮箱，系统将发送重置链接到您的邮箱。

### Q3: 如何修改个人信息？
**A:** 登录后进入"个人中心"，点击"编辑资料"即可修改昵称、头像等信息。

## 产品使用

### Q4: 智能客服支持哪些接入方式？
**A:** 支持网页嵌入、API 接口、微信小程序、APP SDK 等多种接入方式。

### Q5: 知识库如何更新？
**A:** 
- 手动上传：在管理后台上传文档（支持 .md, .txt, .pdf 等格式）
- API 同步：通过接口自动同步知识内容
- 定期训练：系统会自动学习新的问答对

### Q6: 是否支持自定义回复模板？
**A:** 是的，您可以在管理后台设置常用回复模板，提高客服效率。

## 技术服务

### Q7: API 调用有什么限制？
**A:** 
- 免费版：1000 次/天
- 专业版：10 万次/天
- 企业版：不限次数

### Q8: 数据安全如何保障？
**A:** 
- 数据传输采用 HTTPS 加密
- 数据存储进行脱敏处理
- 通过 ISO27001 安全认证
- 定期进行安全审计

### Q9: 技术支持服务时间？
**A:** 
- 在线客服：7×24 小时
- 电话支持：工作日 9:00-18:00
- 紧急响应：全年无休
